# Malabares 🤹‍♂️

Um jogo de puzzle e sobrevivência para mobile onde a concentração e o tempo de reação são a chave. O objetivo é manter o maior número de objetos no ar sem os deixar cair, enquanto se gere o equilíbrio da personagem principal numa corda bamba, lidando com a interferência (positiva ou negativa) de NPCs.

## 🛠️ Tecnologias Utilizadas
* **Motor de Jogo:** Unity
* **Linguagem:** C#
* **Gestão e Documentação:** Notion
* **Controlo de Versões:** Git / GitHub
